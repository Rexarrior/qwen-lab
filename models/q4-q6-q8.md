# Qwen3-0.6B · Q4/Q6 + Q8 embedding

[Download the weights and reproduction files on Hugging Face](https://huggingface.co/rexarrior/Qwen3-0.6B-Q4-Q6-Q8-Embed).

We quantized the official BF16 weights via an F32 intermediate. Of 196 projection matrices, 168 use Q4_K and 28 use Q6_K. The shared input embedding / output head uses Q8_0; all 113 normalization tensors stay in F32. No additional fine-tuning. The calibration input is the importance matrix distributed by [Unsloth](https://huggingface.co/unsloth/Qwen3-0.6B-GGUF); we did not reconstruct its original calibration text.

**Run:** Use the GGUF files from the matching release directory.

```sh
llama-server -m Qwen3-0.6B-OpenResearch-Q4_K_M-Q8-Embed.gguf -c 2048
```
