# Qwen3-0.6B · F5 Terminal Balanced

[Download the weights and reproduction files on Hugging Face](https://huggingface.co/rexarrior/Qwen3-0.6B-F5-Terminal-Balanced).

F5 freezes the [Unsloth UD-IQ2_M base](https://huggingface.co/unsloth/Qwen3-0.6B-GGUF/tree/50968a4468ef4233ed78cd7c3de230dd1d61a56b). For each of 196 projections, a rank-eight correction is reconstructed from packed INT4 codes by a shared 18→64→64→8 decoder with layer-specific FiLM gains and biases. We trained the codes and all 13,064 decoder/FiLM parameters together, giving terminal turns extra weight (1.75; first-token factor 2.5) and using a language KL term (0.05). The base plus compact correction occupied 271.35 MB in the original experiment. The exported adapter is 10.12 MB; it must be loaded alongside the 268.70 MB base at scale 1.

**Run:** Use the GGUF files from the matching release directory.

```sh
llama-server -m Qwen3-0.6B-UD-IQ2_M.gguf --lora Qwen3-0.6B-OpenResearch-F5-Terminal-Balanced-Full-Decoder.gguf -c 2048
```
