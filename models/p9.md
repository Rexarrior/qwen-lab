# Qwen3-0.6B · P9 VQ

[Download the weights and reproduction files on Hugging Face](https://huggingface.co/rexarrior/Qwen3-0.6B-P9-VQ).

Each group of 128 weights has a scale. Fixed indices address a 256-entry codebook of two- or four-weight vectors per projection; the tied embedding uses a 16-entry scalar codebook. The starting books were fitted using calibration activations. P9 trained only the projection codebooks (173,056 parameters) for 112 updates; indices, scales and the embedding stayed fixed.

**Run:** Use the dedicated native server built with both codebooks (see [runtime instructions](../compression/README.md)); stock llama.cpp cannot read this GGUF. Alternatively, decode the portable kit for Transformers.

```sh
./build/bin/llama-server -m Qwen3-0.6B-P9_vq_native-VQ-Native.gguf -c 2048
```
