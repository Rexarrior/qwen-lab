# Qwen3-0.6B · P10 VQ

Each group of 128 weights has a scale. Fixed indices address a 256-entry codebook of two- or four-weight vectors per projection; the tied embedding uses a 16-entry scalar codebook. The starting books were fitted using calibration activations. P10 trained the projection codebooks and group scales for 112 updates, keeping FP32 master books and clamping scales to ±10% of their initial values. Indices and the tied embedding stayed fixed.

**Run:** Use the dedicated native server built with both codebooks (see [runtime instructions](../compression/README.md)); stock llama.cpp cannot read this GGUF. Alternatively, decode the portable kit for Transformers.

```sh
./build/bin/llama-server -m Qwen3-0.6B-P10_vq_native-VQ-Native.gguf -c 2048
```
